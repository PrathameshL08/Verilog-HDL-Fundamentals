# Verilog HDL Fundamentals

## Overview

This repository contains my Verilog HDL practice projects, covering basic digital logic and different types of combinational, sequential, and FSM-based circuits. I am building this repository to improve my understanding of digital design and gain practical experience with RTL design.

The projects are designed and simulated using Xilinx Vivado. Each circuit has its own folder containing the Verilog design, testbench, simulation waveform, RTL schematic, and README file.

## Topics Covered

- **Basic Logic Gates:** AND, OR, NOT, NAND, NOR, XOR, and XNOR gates using dataflow modeling.
- **Combinational Circuits:** Adders, multiplexers, demultiplexers, decoders, and priority encoders.
- **Sequential Circuits:** Flip-flops, counters, and shift-register-based circuits.
- **FSM Design:** Basic Finite State Machine  projects, including a 1101 sequence detector and an even parity detector using Mealy FSMs.

## Tools Used

- Verilog HDL
- Xilinx Vivado

## Repository Structure

- `Basic_Logic_Gates`
- `Combinational_Circuits`
- `Sequential_Circuits`
- `FSM_Design`
 

Each main folder contains separate projects with their own documentation and simulation results.

## Goal

My goal is to strengthen my Verilog HDL and digital design fundamentals through hands-on implementation and gradually move toward more advanced topics in FSM design and RTL design.
