# Verilog HDL Fundamentals

## Overview

This repository contains my Verilog HDL practice projects, covering basic digital logic and different types of combinational and sequential circuits. I am building this repository to improve my understanding of digital design and gain practical experience with RTL design.

The projects are designed and simulated using Xilinx Vivado. Each circuit has its own folder containing the Verilog design, testbench (where available), simulation waveform, RTL schematic, and README file.

## Topics Covered

- **Basic Logic Gates:** AND, OR, NOT, NAND, NOR, XOR, and XNOR gates using dataflow modeling.
- **Combinational Circuits:** Adders, multiplexers, demultiplexers, decoders, and priority encoders.
- **Sequential Circuits:** Flip-flops, counters, and shift-register-based circuits.

## Tools Used

- Verilog HDL
- Xilinx Vivado

## Repository Structure

- `Basic_Logic_Gates/`
- `Combinational_Circuits/`
- `Sequential_Circuits/`

Each main folder contains separate projects with their own documentation and simulation results.

## Goal

My goal is to strengthen my Verilog HDL and digital design fundamentals through hands-on implementation and gradually move toward more advanced topics such as finite state machines (FSMs) and RTL design.
