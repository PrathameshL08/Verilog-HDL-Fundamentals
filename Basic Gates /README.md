## Basic Logic Gates — Verilog HDL
This folder contains my implementation of basic digital logic gates using Verilog HDL.
All designs are written using Dataflow Modeling with continuous assignment statements.
Testbenches are included for the gates that were simulated and verified.

## Gates Implemented 
- AND  :  `Y = A & B`  	
- OR	  :  `Y = A | B`	 
- NOT  :	 `Y = ~A`	      
- NAND :  `Y = ~(A & B)` 
- NOR	 :  `Y = ~(A | B)`	
- XOR	 :  `Y = A ^ B	`
- XNOR :  `Y = ~(A ^ B)`
